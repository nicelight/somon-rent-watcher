# Manual scan result does not explain search coverage

`internal/telegram/bot.go:CompleteManualPoll` reports no fresh matching ads for
zero sends, while `internal/app/app.go:processNewCards` excludes every seen ID
before filtering. The production comparison found 38 already-seen IDs among
60 ad links on the operator's filtered website page. The message does not
explain that scanning cannot revisit these ads or search the entire filtered
catalogue. This contributed to the reported expectation mismatch; no UI or
runtime change was made during diagnosis.

# Price parsing joins adjacent numeric text

Live HTML comparison reproduces category price 65000 for the real price 5000
on IDs 17094278/17075880. ID 17087959 has visible price 4800 but category
74800 and detail 314800 (title ends with `д-31`). `parseCategoryDOM` parses
broad card text; `detailPrice` falls back to broad page text, while `parsePrice`
allows whitespace-separated digits. The dedicated visible price block avoids
the neighbouring numbers in the diagnostic probe. Eleven of fourteen suitable
ads in the checked 60-card sample fail the installed card-price prefilter.
Evidence: `.protocols/diagnostics/production-search-audit-2026-09-09/report.md`.
No implementation fix was made in this read-only runtime investigation.

Resolution: final hotfix `93cbe9ebcfe6` scopes price extraction to its own DOM data,
adds regression coverage and is deployed. Seen history is intentionally preserved.

# Firewall fingerprint included traffic counters

The hotfix read-only host probe originally removed iptables-save timestamp comments
but retained policy packet/byte counters. Its pre/post hashes therefore differed
without establishing a rule change. Corrected the probe to normalize those counters;
two postflight rule fingerprints match. The original before fingerprint cannot be
retroactively normalized, so the verification records this limitation instead of
claiming that comparison passed. No firewall-modifying command was executed.

Final deployment used normalized firewall fingerprints captured before and after the
release; they match. Explicit `Цена:` price-line compatibility is retained and verified
by a price assertion in the existing missing-seller fixture test.
