# Papercuts

- На момент brownfield-маппинга корень проекта не был Git-репозиторием. Git был инициализирован перед первой публичной публикацией; история до инициализации остаётся недоступной.
- В текущем workspace отсутствует executable `go`: `go version` завершается с `go: command not found`. Поэтому project-native Go checks нельзя воспроизвести локально до установки Go toolchain и SQLite build prerequisites.
- На initial import глобальный `git diff --cached --check` сообщает trailing whitespace в сгенерированных DevRails `.mjs` files и исходных Markdown hard-break lines. Это pre-existing formatting, не связанный с public-sanitization изменениями; исправление generated framework files не входит в текущий scope.
